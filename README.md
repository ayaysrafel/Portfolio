# Amitiel Espinosa | Portfolio Website

My personal freelance portfolio, built with HTML, CSS, JavaScript, PHP and MySQL.

## Features
- Responsive design for phones and desktops
- Contact form that saves messages to a MySQL database
- Password-protected admin page to read messages
- Gmail button that opens a pre-filled email

## Run it locally
1. Install XAMPP and start Apache and MySQL.
2. Copy this folder into `htdocs`.
3. Import `database/portfolio.sql` in phpMyAdmin.
4. Copy `config.sample.php` to `php/config.php` and enter your own database details and admin password.
5. Open `http://localhost/portfolio/`.
